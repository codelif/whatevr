# what-assets

whatevr's bundled assets: fonts now, icons and sounds later.

Files are compiled into the binary, so nothing is looked up at run time.

## Fonts

- Instrument Sans v1.000, variable (wdth 75-100, wght 400-700), roman and
  true italic. From github.com/Instrument/instrument-sans, identical to the
  google/fonts copy. SIL Open Font License 1.1, see `fonts/OFL.txt`.

## Boundaries

- Depends on no workspace crate.
- One of the crates that know whatevr exists (the others are what-chat, what-proto and whatgui).
