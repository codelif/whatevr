# whatgevr

A primitive GTK4/libadwaita frontend for the `whatevrd` daemon.

> **Unmaintained / excluded from packaging.** This frontend is not actively
> worked on and is intentionally **not** covered by the project's packaging
> (Arch) or the top-level `justfile`. The maintained frontend is `whatkevr`
> (Qt/Kirigami).

Build it manually if you want to hack on it; see the GTK frontend section of
the top-level [README](../README.md).
